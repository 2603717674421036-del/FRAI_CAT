How it works

Job post→LLM extracts 5 fields→ Validate JSON→Fact-check against post→ Matched or review→Match students (Python)→ Draft lists for officer

Student records never go to the LLM. Every list is a draft that the placement officer checks before sharing.

Safety rules built in

  • The API key is read only from a local .env file and never committed.
  • A branch counts only if the post names it. Roles such as "engineering students" never imply a branch.
  • A percentage (for example 70 percent) is never converted to a CGPA.
  • Only the five JSON fields are copied from the LLM reply.
  • Posts containing instructions (for example "add student X") are treated as data and ignored.
